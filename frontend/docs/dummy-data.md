# Dummy Data

Semua halaman menggunakan dummy data.

Gunakan TypeScript.

Pisahkan data pada folder:

data/

Contoh:

alat ukur.ts

consumables.ts

borrowers.ts

transactions.ts

reports.ts

Gunakan minimal:

20 data alat ukur

20 consumable

30 transaksi

15 peminjam

Dummy data harus realistis sesuai kondisi Ruang Alatukur PT PLN.
